A computer on your network

Chat with a bigger model running on your own PC or Mac

MemoryAI can use a model that runs on a computer on your home Wi‑Fi: the phone finds the computer, lists its models and chats with them, and nothing leaves your network. The phone side takes four taps. The computer side is below, step by step, for Windows, macOS and Linux — the same steps the app shows in its checklist, here so you can read them on the computer while you follow them.

Works with Ollama (free, open source) or LM Studio. A model of 4–9 billion parameters runs well on a computer with 16 GB of memory, and that is where the computer beats the phone; under 8 GB it is no better than the phone.

On the phone

  • Open the Models tab and tap Connect a computer.
  • Tap Search the network. The phone looks at the addresses of your Wi‑Fi for a few seconds — nothing runs until you tap.
  • Tap Connect on the computer it found. Its models appear in the Models tab with a LAN badge: tap Use on one and chat as usual.
  • If nothing is found, the app opens its checklist; the Test button beside a typed address tells you which step is missing.

Windows

WindowsmacOSLinux

  1. Install Ollama or LM Studio

    Download Ollama from ollama.com/download (or LM Studio from lmstudio.ai) and open it once.

  2. Get a model

    Pick the line for your computer's memory and run it in PowerShell or the Command Prompt:

    8 GB of RAM, no graphics card: ollama pull qwen3.5:4b (3.3 GB)

    16 GB of RAM, or a graphics card with 8 GB: ollama pull qwen3.5:9b (6.6 GB)

    32 GB of RAM, or a graphics card with 16 GB or more: ollama pull gpt-oss:20b (13.8 GB)

    Under 8 GB the computer is no faster than the phone: use the phone's own model. A model needs about 1 GB of memory per billion parameters, plus room for the conversation. Any model from ollama.com/library works the same way: gemma4:e4b (6.6 GB) reads images, gemma4:26b (18.7 GB) wants a graphics card with 24 GB. In LM Studio, search the same names in its catalogue.

  3. Let it listen on your network

    By default Ollama answers only the computer itself. Set the variable, then quit Ollama from the system tray and open it again:

    setx OLLAMA_HOST 0.0.0.0

    LM Studio: Developer → Server, switch on Serve on local network.

  4. Open the firewall

    PowerShell as administrator:

    New-NetFirewallRule -DisplayName "Ollama" -Direction Inbound -Protocol TCP -LocalPort 11434 -Action Allow

    For LM Studio use port 1234 instead of 11434.

  5. Same Wi‑Fi, no VPN

    Phone and computer on the same network. A guest network, a VPN on either side or a mobile hotspot keeps them apart.

  2. Get a model

Linux

WindowsmacOSLinux

  1. Install Ollama

    In a terminal:

    curl -fsSL https://ollama.com/install.sh | sh

    LM Studio for Linux is an AppImage from lmstudio.ai.

  2. Get a model

    Pick the line for your computer's memory and run it in a terminal:

    8 GB of RAM, no graphics card: ollama pull qwen3.5:4b (3.3 GB)

    16 GB of RAM, or a graphics card with 8 GB: ollama pull qwen3.5:9b (6.6 GB)

    32 GB of RAM, or a graphics card with 16 GB or more: ollama pull gpt-oss:20b (13.8 GB)

    Under 8 GB the computer is no faster than the phone: use the phone's own model. A model needs about 1 GB of memory per billion parameters, plus room for the conversation. Any model from ollama.com/library works the same way: gemma4:e4b (6.6 GB) reads images, gemma4:26b (18.7 GB) wants a graphics card with 24 GB. In LM Studio, search the same names in its catalogue.

  3. Let it listen on your network

    For one session:

    OLLAMA_HOST=0.0.0.0 ollama serve

    For the service installed by the script, set the variable for good:

    sudo systemctl edit ollama
# add these two lines, save, then:
[Service]
Environment="OLLAMA_HOST=0.0.0.0"
sudo systemctl restart ollama

  4. Open the firewall

    With ufw (Ubuntu, Debian):

    sudo ufw allow 11434/tcp

    With firewalld (Fedora):

    sudo firewall-cmd --permanent --add-port=11434/tcp && sudo firewall-cmd --reload

  5. Same Wi‑Fi, no VPN

    Phone and computer on the same network. A guest network, a VPN on either side or a mobile hotspot keeps them apart.

Check it

  • On the computer, open http://localhost:11434 in a browser: the page says Ollama is running.
  • On the phone's browser, open http:// followed by the computer's address and :11434 (for example http://192.168.1.10:11434): the same line. If the phone's browser gets nothing, the firewall or the network is in the way — steps 3 to 5.
  • In MemoryAI, Search the network again, or type the address and tap Test: the test says which step is missing.

Privacy

The app talks to your computer over your private network only (addresses that start with 192.168, 10 or 172.16–31) and never to a public address. Your questions and the model's answers travel between the phone and the computer, inside your home, and nowhere else. An API key, when a server asks for one, is kept in the phone's secure storage.
